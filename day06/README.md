# Tag 6 – Präsentieren: Von der Idee zur überzeugenden Präsentation

Begleitmaterial zum Onlinekurs **„Künstliche Intelligenz in der Arbeitswelt“**.

## Lernziel

Ihr lernt, eine Präsentation zielgruppenorientiert vorzubereiten, Aussagen und Quellen zu prüfen, eine verständliche Dramaturgie zu entwickeln und KI-Werkzeuge sinnvoll für die Umsetzung einzusetzen. Schwerpunkt im Unterricht sind Live-Demonstrationen. Die Aufgaben können anschließend in Ruhe bearbeitet werden.

## So arbeitet ihr mit dem Material

1. Öffnet das [Demo-Briefing](materialien/01_demo_briefing_lokale_ki.md), das wir im Unterricht gemeinsam verwenden.
2. Ergänzt bei Bedarf das [Quellenpaket](materialien/02_quellenmaterial_lokale_ki.md).
3. Nutzt ChatGPT, Gamma, NotebookLM oder einen anderen verfügbaren Assistenten.
4. Prüft die Ausgabe mithilfe der [Qualitätscheckliste](materialien/03_praesentations_checkliste.md).
5. Wählt eine der freiwilligen [Vertiefungsaufgaben](uebungen/).

Die fiktive Organisation und alle unternehmensbezogenen Angaben sind erfunden. Nutzt für eigene Versuche keine vertraulichen oder personenbezogenen Daten ohne entsprechende Freigabe.

## Technische Hinweise

- **ChatGPT und Gamma** werden im Unterricht live gezeigt.
- **NotebookLM** wird anhand ausgewählter Quellen demonstriert.
- **Claude, PowerPoint und Microsoft Copilot** werden im Vergleich beschrieben, nicht live vorgeführt.
- Funktionen sind abhängig von Tarif, Rollout und Organisationseinstellungen. Ihr benötigt nicht zwingend kostenpflichtige Funktionen, um die grundlegenden Aufgaben als Konzept- und Strukturarbeit im Chat zu bearbeiten.
